# 📌 Pinterest Clone

Une reproduction moderne de l’interface Pinterest en version Web & Mobile, développée avec **HTML, CSS et JavaScript** sur VSCode.

## ✨ À propos du projet

Ce projet a été réalisé dans le but de progresser en :

- Front-end Development
- UI/UX Design
- Responsive Design
- Création d’interfaces inspirées des applications modernes

## 🎨 Fonctionnalités

- Interface inspirée de Pinterest
- Version Web & Mobile responsive
- Design naturel et moderne
- Animations et interactions personnalisées
- Expérience utilisateur fluide

## 📸 Ressources utilisées

- Photos prises par moi-même
- Icônes modifiées/créées afin de respecter les droits d’auteur
